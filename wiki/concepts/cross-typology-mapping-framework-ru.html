Рамка межтипологического сопоставления #

Обзор #

Предлагаемый процесс для экспериментов с мостами между тремя типологическими системами (темпористикой, психософией, соционикой) и более распространёнными моделями черт. Эта страница фиксирует архитектурные идеи проекта и подход к эмпирической проверке через опросы, а не симуляцию или установленный стандарт сопоставления.

Архитектура процесса #

┌─────────────────────────────────────────────────────────┐
│  СЛОЙ МЕЖТИПОЛОГИЧЕСКОГО СОПОСТАВЛЕНИЯ                 │
│                                                         │
│  Темпористика (24 типа) ──→ MBTI/Юнг (16 типов)         │
│  Психософия (81 тип)   ──→ MBTI/Юнг (16 типов)          │
│  Соционика (16 типов)  ──→ MBTI/Юнг (16 типов)          │
│                        ↓                                │
│              PersonaNexus (мост черт)                   │
│              OCEAN ↔ DISC ↔ Юнг ↔ пользовательские      │

                        ↓
┌─────────────────────────────────────────────────────────┐

Межсистемное сопоставление #

Соционика Распространённое приближение MBTI Примечание
ILE ENTP Распространённое сопоставление в сообществе
LIE ENTJ Распространённое сопоставление в сообществе
EIE ENFJ Распространённое сопоставление в сообществе
IEE ENFP Распространённое сопоставление в сообществе
ILI INTP или INTJ Спорно
LII INTP или INTJ Спорно
EII INFJ Распространённое, но всё равно приблизительное

Темпористика → MBTI (гипотеза) #

Измерение временной рамки сопоставляется с предпочтениями когнитивного стиля:

Рамка темпористики Основное предпочтение Вторичное
Типы Настоящего (1-4N) Сенсорика (конкретное) Se/Si
Типы Будущего (1-4F) Интуиция (абстрактное) Ne/Ni
Типы Вечности (1-4E) Рефлексия (Ni/Si) Сбалансированное
Типы Прошлого (1-4P) Ориентация на память Преобладание Si

Подход к сопоставлению: сочетания аспектов темпористики сопоставляются с юнгианскими дихотомиями:

  • временной фокус (P/N/F/E) → предварительные признаки ориентации;
  • плотность аспекта → предпочтение S/N;
  • роль аспекта → T/F и J/P.

Психософия → MBTI (гипотеза) #

Четырёхаспектная структура сопоставляется через взвешивание функций:

Паттерн психософии Возможное подобие MBTI Примечания
Преобладание Логики Акцент на мышлении Только приближение
Преобладание Эмоции Акцент на чувстве Только приближение
Преобладание Физики Акцент на сенсорике Только приближение
Преобладание Воли Акцент на суждении / агентности Только приближение

Пример гипотезы для проверки #

Сочетание темпористики и соционики предсказывает удовлетворённость лучше, чем каждая система отдельно #

  • Метод: интервью и структурированные опросы на OASIS-platform с 200 реальными парами.
  • Метрика: многофакторная регрессия с перекрёстной проверкой.
  • Ожидание: проверить, улучшают ли объединённые признаки прогноз по сравнению с базовыми моделями одной системы.

Справка об инструментах #

PersonaNexus #

  • Назначение: декларативное описание личности с сопоставлением между моделями.
  • Основные возможности: двунаправленное OCEAN↔DISC↔Jungian, файлы идентичности YAML, наследование архетипов.
  • Команда: pip install personanexus
  • Пример: personanexus personality jungian-to-traits --preset intj

Примечание аудита: проверка поставщика и источников этого набора инструментов в текущем репозитории не завершена; ссылки на инструменты следует считать исследовательскими указателями.

OASIS-platform (опросные интервью) #

  • Назначение: качественные исследовательские интервью и сбор опросов.
  • Основные возможности: помощь в голосовых/текстовых интервью, транскрибация и кодирование с несколькими LLM, развёртывание Docker, соответствие FAIR.
  • Установка: git clone https://github.com/oasis-surveys/oasis-platform && docker compose up
  • Лицензия: Open Non-Commercial Research License v1.0.
