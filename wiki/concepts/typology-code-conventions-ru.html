Правила записи типологических кодов

Эта страница определяет, как в wiki записываются коды типов на английских, русских и украинских страницах.

Правило #

Основным должен быть код на языке страницы. Эквиваленты на других языках добавляются в скобках, когда важна надёжность межъязыкового сопоставления.

Пример:

  • Английская страница: SLI + ELVF + EPNF (RU: СЛИ + ЭЛВФ + ВПНБ; UK: СЛІ + ЕЛВФ + Вч-Ми-Тп-Мб)
  • Русская страница: СЛИ + ЭЛВФ + ВПНБ (EN: SLI + ELVF + EPNF; UK: СЛІ + ЕЛВФ + Вч-Ми-Тп-Мб)
  • Украинская страница: СЛІ + ЕЛВФ + Вч-Ми-Тп-Мб (EN: SLI + ELVF + EPNF; RU: СЛИ + ЭЛВФ + ВПНБ)

Не смешивайте языковые варианты кодов в одном предложении, если оно не предназначено для явного перечисления эквивалентов.

Соционика #

Соционические коды также следует локализовать, если для языка страницы существует устоявшаяся аббревиатура. Для межъязыкового поиска сохраняйте латинский код в скобках.

Значение Английский Русский Украинский
Сенсорно-логический интроверт SLI СЛИ (SLI) СЛІ (SLI)

Аналоги из MBTI можно приводить для ориентации, но это не эквивалентные системы. Соционический SLI часто приблизительно сопоставляют с ISTP в MBTI и с прежней соционической записью ISTp.

Соционика Русский Украинский Прежняя запись Приблизительный аналог MBTI
SLI СЛИ СЛІ ISTp ISTP, только приблизительно

Информационные элементы при необходимости можно показывать на нескольких языках:

Латиница Русский Украинский
Si БС БС
Te ЧЛ ЧЛ
Ni БИ БІ
Fe ЧЭ ЧЕ
Ne ЧИ ЧІ
Fi БЭ БЕ

Темпористика #

В английском используется N для Present/Now, чтобы не смешивать его с P = Past.

В русском используются устоявшиеся однобуквенные кириллические коды.

В украинском используются двухбуквенные коды проекта, поскольку Минуле и Майбутнє начинаются с одной буквы.

Аспект Английский код Русский код Украинский код
Вечность E В Вч
Прошлое P П Ми
Настоящее / сейчас N Н Тп
Будущее F Б Мб

Составной пример для Вечность — Прошлое — Настоящее — Будущее:

Язык Код
Английский EPNF
Русский ВПНБ
Украинский Вч-Ми-Тп-Мб

Коды позиций #

При записи позиций используйте локальные коды аспектов:

Значение Английский Русский Украинский
1-я Вечность 1E 1В 1Вч
2-е Прошлое 2P 2П 2Ми
3-е Настоящее 3N 3Н 3Тп
4-е Будущее 4F 4Б 4Мб

Это уменьшает неоднозначность между системами. Например, английское 4F может означать 4-ю Физику в психософии или 4-е Будущее в темпористике, поэтому при возможной неоднозначности следует явно называть систему.
