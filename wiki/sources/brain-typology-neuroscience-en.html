Historical Exploratory Note on Brain Regions and Typology Systems

Historical Exploratory Note on Brain Regions and Typology Systems #

This page is a historical exploratory note. It records early candidate analogies between typological constructs and neuroscience topics, but it should not be read as a validated brain-type map.

Current Before We Build policy: neuroscience is an external context layer for mechanism hypotheses, measurement design, and safety caveats. Do not infer typological type from brain regions, and do not infer brain pathology from typological type.

Jung's Cognitive Functions and Brain-Region Claims #

Some authors, including Katherine Benziger and Dario Nardi, have proposed correlations between Jungian function language and broad brain areas. Treat these as speculative source claims rather than established neuroscience.

Source claim Proposed broad area Status
Thinking-language claims Left frontal areas Historical/speculative source claim
Feeling-language claims Right posterior areas Historical/speculative source claim
Sensing-language claims Left posterior areas Historical/speculative source claim
Intuition-language claims Right frontal areas Historical/speculative source claim

Sources: Benziger (2013), Nardi (2020)

Extraversion vs Introversion #

Eysenck's arousal theory has been used historically to discuss extraversion/introversion and the Reticular Activating System (RAS). This is a broad trait-theory claim, not a Socionics or Before We Build type marker:

  • arousal-level hypotheses may inform general personality research;
  • they should not be used to infer Socionics extraversion/introversion;
  • they should not be used as clinical evidence.

This section is retained only as source-history context.

Time Processing and Brain Networks #

The brain has distinct systems for processing past, present, and future:

Past (Episodic Memory)

  • Hippocampus — binds details into cohesive episodic memories
  • Posterior cingulate cortex (PCC) — retrieves autobiographical memories
  • Medial temporal lobe — pattern separation for memory encoding

Present (Current State)

  • Somatosensory cortex — body-based "here and now" awareness
  • Anterior cingulate cortex (ACC) — monitors ongoing actions
  • Precuneus — self-awareness in current moment

Future (Prospection)

  • Ventromedial prefrontal cortex (vmPFC) — constructs future scenarios
  • Default Mode Network (DMN) — internally-generated simulation
  • Lateral prefrontal cortex — prospective planning

Meaning-Making and Abstract Orientation

  • Default Mode Network — self-projection across time
  • Medial prefrontal cortex — meaning-making, values
  • Dorsolateral PFC — abstract reasoning

Sources: Frontiers in Temporal Cognition (2025), Nature Scientific Reports (2025)

Emotion Processing and Brain Regions #

Emotion-related typology language may be compared cautiously with general affective-neuroscience constructs. This does not mean Psychosophy's Emotion aspect, or any type position, is identical to these circuits.

Process Brain Regions Role
Emotion Generation Amygdala, Ventral Striatum Reactive emotional response
Emotion Regulation Ventromedial PFC, ACC Top-down regulation
Value Computation Orbitofrontal Cortex (OFC) Reward/punishment valuation
Social Emotion Anterior Insula, pgACC Interpersonal resonance

Sources: Nature Reviews Neuroscience (2015), Cortex (2017)

Removed Mapping Table #

An earlier version of this page contained a typology-to-brain-domain table. That table has been removed because it invited overinterpretation. Future neuroscience work should start from independently measurable cognitive or affective constructs, then ask whether Before We Build scenarios generate testable behavioral hypotheses.

Big Five → Brain Networks #

Research by Jung & Chohan (2019) links Big Five to brain networks:

Trait Brain Network Key Regions
Openness/Intellect Cognitive Control Network DLPFC, ACC
Openness/Creativity Default Mode Network PCC, mPFC
Conscientiousness Fronto-Striatal DLPFC, Pre-SMA
Extraversion Reward Networks Ventral Striatum, OFC
Agreeableness Emotion/Social Networks Anterior Insula, pgACC
Neuroticism Limbic Networks Amygdala, Hippocampus

Source: "Three Individual Difference Constructs, One Converging Concept" (2019)

Methodological Notes #

1. fMRI limitations: Most findings are correlational, not causal

2. Individual variation: Brain region functions vary significantly between individuals

3. Network dynamics: Single regions participate in multiple networks

4. These are analogies: Not confirmed typology mappings

5. Clinical boundary: Neurological symptoms require clinical evaluation and should not be interpreted through typology alone

Source Assessment #

What the Source Claims #

Historical authors proposed analogies between Jungian or typological language and brain regions, while contemporary research describes distributed networks for memory, prospection, emotion, and valuation.

Data or Evidence Provided #

The page attributes books, neuroscience papers, and meta-analyses; it contains no independent neuroimaging data or validated BWB biomarker.

Limitations #

Most cited findings are correlational and task-dependent, brain regions are multifunctional, and the typological constructs were not directly operationalized in the cited studies.

What BWB Accepts #

BWB accepts neuroscience as external context for candidate processes, measurement design, and safety caveats.

What Remains Contested or Open #

Any mapping from a BWB construct to a network, region, or causal process remains contested until directly and independently tested.

Rejected or Historical-Only #

BWB rejects brain-region typing, neurological diagnosis from a type description, and the removed one-to-one mapping table except as historical record.
